# Base Search 1.0.0

Base Search відкриває таблиці, шукає в усіх вихідних стовпцях і формує зведення та експорт на вашому комп’ютері.

1. Завантажте архів для своєї системи зі сторінки [Releases](https://github.com/IvanK577/BaseSearch/releases) і повністю розпакуйте його. У Windows відкрийте `Start Base Search.cmd`, у macOS — `Start Base Search.command`, в Ubuntu запустіть `./"Start Base Search.sh"` із розпакованої папки. Для Ubuntu також доступний пакет `.deb`.
2. Виберіть **Додати файли** або **Перенести базу 2.2.0**. У російськомовному інтерфейсі ці дії називаються **Добавить файлы** та **Перенести базу 2.2.0**.
3. Перегляньте аркуші, за потреби змініть призначення стовпців і підтвердьте завантаження. Знайдіть записи, відкрийте підсумки або збережіть вибірку в CSV чи XLSX.
