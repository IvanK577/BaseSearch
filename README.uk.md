# Base Search 1.0.0

Base Search відкриває таблиці, шукає в усіх вихідних стовпцях і формує зведення та експорт на вашому комп’ютері.

1. Виберіть пакет на сторінці [Releases](https://github.com/IvanK577/BaseSearch/releases). Для Windows 11 x64 використовуйте `.exe`, для macOS 14 або новішої — `.dmg` відповідної архітектури, для Ubuntu 22.04 та 24.04 x64 — `.deb`.
2. Відкрийте програму з меню застосунків. Виберіть **Додати файли** або **Перенести базу 2.2.0**. У російськомовному інтерфейсі ці дії називаються **Добавить файлы** та **Перенести базу 2.2.0**.
3. Перегляньте аркуші, за потреби змініть призначення стовпців і підтвердьте завантаження. Знайдіть записи, відкрийте підсумки або збережіть вибірку в CSV чи XLSX.
