# Base Search 1.0.0

Base Search хранит таблицы на вашем компьютере. Добавляйте файлы, ищите строки по любому исходному полю, сверяйте сводки и выгружайте отфильтрованные результаты.

[Українська коротка інструкція](README.uk.md)

## Установка и первый запуск

1. На странице [Releases](https://github.com/IvanK577/BaseSearch/releases) выберите пакет своей системы. Проверочные пакеты ветки доступны в результатах GitHub Actions.
2. На Windows 11 x64 запустите установщик `.exe`. На macOS 14 и новее откройте `.dmg` для Intel или Apple Silicon и перенесите Base Search в «Программы». На Ubuntu 22.04 и 24.04 x64 откройте `.deb` через менеджер пакетов.
3. Откройте Base Search из меню приложений. Нажмите **Добавить файлы** или **Перенести базу 2.2.0**.

Приложение работает в одном окне. Windows-установщик содержит автономную установку WebView2. Для открываемого обычным способом публичного пакета macOS используется Developer ID и нотарификация Apple.

## Работа с данными

- **Данные** показывает файлы и листы после импорта. В предпросмотре можно поменять назначение столбцов и указать фиксированную валюту или единицу веса для листа.
- **Поиск** ищет текст в исходных значениях. Фильтры, порядок строк и выбор столбцов видны рядом с таблицей. Карточка строки показывает значения и источник.
- **Сводка** считает данные активного запроса по месяцам, компаниям и товарам. Валюты показаны отдельно, вес приводится к килограммам при известной единице. Нажмите на группу, чтобы открыть её строки.
- **Выгрузить** сохраняет всю текущую выборку в CSV или XLSX. Можно выбрать видимые или все столбцы. CSV использует UTF-8 и защищает формульные строки при открытии в редакторе таблиц. XLSX сохраняет исходный текст и разделяет большие результаты между листами.

Поддерживаются CSV, TSV, XLSX, XLSM, XLSB, XLS и ODS. Ведущие нули сохраняются в текстовых ячейках. Пользовательские маски числовых ячеек Excel требуют сохранения кодов как текста до загрузки. Чтение листов старого XLS и ODS требует памяти на диапазон листа. Крупные CSV, TSV, XLSX, XLSM и XLSB читаются порциями, с учётом памяти на служебные структуры книги.

При переносе выберите файл базы 2.2.0. Приложение создаёт отдельную `workspace.sqlite` в папке данных текущего профиля. Для сравнения результаты переноса сверяются по файлам, листам и содержимому записей. Номера строк, отсутствующие в базе 2.2.0, оставляются пустыми.

## Сборка и проверки

Инструменты сборки — Rust 1.96, Node.js 22 и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

```sh
npm ci
npm ci --prefix app-ui
npm run dev
```

`npm run build -- --bundles nsis` собирает пакет Windows. На macOS используйте `dmg`, на Linux — `deb`. Автоматические проверки находятся в `.github/workflows/ci.yml`.

```sh
npm --prefix app-ui run test:unit
npm --prefix app-ui run build
cargo test --locked --workspace --all-targets --features base-search-desktop/custom-protocol
cargo run --release --locked -p base-search-core --example scale -- 1000000
cargo run --release --locked -p base-search-core --example scale -- 10000000
```

Проверка масштаба сама создаёт временный CSV и сравнивает количество строк после импорта, повторного открытия, поиска и выгрузки. Для крупных испытаний нужен свободный диск на исходный CSV, индекс, базу и выгрузку.

Исторический выпуск доступен по тегу [`legacy-v2.2.0`](https://github.com/IvanK577/BaseSearch/tree/legacy-v2.2.0). Лицензия [MIT](LICENSE).
